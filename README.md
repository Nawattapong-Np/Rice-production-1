 คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **Rice Production Analysis**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Rice production (ปริมาณผลผลิตข้าวรายประเทศ/พื้นที่ รายปี) |
| แหล่งที่มาเดิม | (โปรดระบุลิงก์ต้นทางของชุดข้อมูลที่ดาวน์โหลดมา) |
| ประเภทข้อมูล | ข้อมูลสถิติรายปีระดับประเทศ/พื้นที่ (panel data) 1 แถวต่อ 1 พื้นที่ต่อ 1 ปี ช่วงปี 1961–2021 |

**หมายเหตุ:** รูปแบบคอลัมน์ในไฟล์ดิบสอดคล้องกับข้อมูลที่ส่งออกจาก FAOSTAT แต่ตัวไฟล์ไม่ได้ระบุแหล่งที่มา ควรตรวจสอบและระบุแหล่งที่มา/เงื่อนไขการใช้ข้อมูลให้ชัดเจนก่อนเผยแพร่

## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| `data/raw/Rice production.csv` | ไฟล์ดิบตามที่ดาวน์โหลดมา **ห้ามแก้ไขด้วยมือ** มี 7,324 แถว 6 คอลัมน์ |
| `data/processed/rice_clean.csv` | ข้อมูลที่ล้างแล้ว 7,324 แถว 7 คอลัมน์ **สร้างจาก** `code/01_clean_data.py` |

วิธีสร้างไฟล์ที่ประมวลผลแล้วขึ้นใหม่: วางไฟล์ดิบที่ `data/raw/Rice production.csv` แล้วรัน `python code/01_clean_data.py`

**สิ่งที่สคริปต์ล้างข้อมูลทำ**
- เปลี่ยนชื่อคอลัมน์เป็นรูปแบบ snake_case และเปลี่ยนชื่อ `Value` เป็น `value_tonnes` เพื่อระบุหน่วย
- แก้ชื่อพื้นที่ที่อักขระเพี้ยน 3 ชื่อ: `C?te d'Ivoire` → `Côte d'Ivoire`, `R?union` → `Réunion`, `T?rkiye` → `Türkiye`
- เปลี่ยนค่า 0 ที่มี `Flag = M` (161 แถว) เป็นค่าว่าง เพราะเป็นข้อมูลที่ไม่มีหรือไม่เกี่ยวข้อง ไม่ใช่ผลผลิตเป็นศูนย์
- ลบแถวซ้ำของ (`area`, `year`) และแถวที่ค่าติดลบ (ไฟล์นี้ไม่มีทั้งสองกรณี จึงไม่มีแถวถูกลบ)
- เพิ่มคอลัมน์ `area_type` เพื่อจำแนกพื้นที่ที่อาจนับซ้ำหรือไม่มีแล้ว

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `rice_clean.csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 7,324 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชื่อคอลัมน์เดิม | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | --- | ---: |
| `area` | Area | ข้อความ | ชื่อประเทศหรือพื้นที่ มี 149 ค่า เช่น Thailand, India, China, Viet Nam, Indonesia | 0 |
| `year` | Year | ตัวเลขจำนวนเต็ม | ปีของข้อมูล ตั้งแต่ 1961 ถึง 2021 (61 ปี) | 0 |
| `unit` | Unit | ข้อความ | หน่วยของปริมาณผลผลิต มีค่าเดียวคือ `tonnes` (ตัน) | 0 |
| `value_tonnes` | Value | ตัวเลขทศนิยม | ปริมาณผลผลิตข้าวต่อปี หน่วยเป็นตัน เป็นตัวแปรหลักสำหรับการวิเคราะห์ ค่าสูงสุด 214,429,900 ตัน แถวที่ `flag = M` ถูกเปลี่ยนเป็นค่าว่าง | 161 |
| `flag` | Flag | ข้อความ | รหัสบอกที่มา/คุณภาพของค่า ได้แก่ A, E, I, T, M (ดูตารางด้านล่าง) | 0 |
| `flag_description` | Flag Description | ข้อความ | คำอธิบายของรหัสใน `flag` | 0 |
| `area_type` | (สร้างใหม่) | ข้อความ | ประเภทของพื้นที่: `country`, `component`, `historical`, `aggregate` (ดูตารางด้านล่าง) | 0 |

### ความหมายของ `flag`

| `flag` | `flag_description` | จำนวนแถว |
| --- | --- | ---: |
| A | Official figure (ตัวเลขทางการ) | 6,164 |
| E | Estimated value (ค่าประมาณ) | 506 |
| I | Imputed value (ค่าที่เติมโดยการคำนวณ) | 279 |
| T | Unofficial figure (ตัวเลขไม่เป็นทางการ) | 214 |
| M | Missing value (data cannot exist, not applicable) | 161 |

### ความหมายของ `area_type`

| `area_type` | คำอธิบาย | จำนวนแถว |
| --- | --- | ---: |
| `country` | ประเทศ/พื้นที่ทั่วไป | 6,967 |
| `component` | ส่วนย่อยของจีน ได้แก่ China, mainland / China, Hong Kong SAR / China, Taiwan Province of | 183 |
| `historical` | หน่วยทางประวัติศาสตร์ที่ไม่มีแล้ว ได้แก่ USSR, Yugoslav SFR, Sudan (former) | 113 |
| `aggregate` | `China` ซึ่งเป็นผลรวมของส่วนย่อยข้างต้น | 61 |

**หมายเหตุ**
- จำนวนค่าว่าง (Missing Values) นับจากข้อมูลหลังทำความสะอาดแล้ว จำนวน 7,324 แถว
- หลังล้างข้อมูลยังมีแถวที่ `value_tonnes = 0` อีก 159 แถว เป็นค่าที่มาจากแหล่งข้อมูลจริง (`flag` เป็น A, E หรือ I) ไม่ได้ถูกแปลงเป็นค่าว่าง
- ก่อนรวมผลหรือเรียงอันดับ ควรกรอง `area_type` ให้เหลือ `country` เพื่อไม่ให้นับซ้ำระหว่าง `China` กับส่วนย่อย
- จำนวนปีไม่เท่ากันในแต่ละพื้นที่ (4–61 ปี) จึงเป็นข้อมูลแบบไม่สมดุล (unbalanced panel)

หน่วยของปริมาณผลผลิตทั้งหมดคือตัน (tonnes)
